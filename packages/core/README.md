# @tracethrough/core

Shared building blocks of TraceThrough: the event schema (Zod), the redaction engine, body previews, a ring buffer, filtering, HAR/JSON export and W3C trace context helpers.

Part of [TraceThrough](https://github.com/solomonade1/tracethrough), a developer network inspector. Download the app from the [latest release](https://github.com/solomonade1/tracethrough/releases/latest), then follow the steps below. Full guide: [Connect your own app](https://github.com/solomonade1/tracethrough#connect-your-own-app).

Most people do not install this directly. It is a dependency of [@tracethrough/node](https://www.npmjs.com/package/@tracethrough/node) and [@tracethrough/next](https://www.npmjs.com/package/@tracethrough/next).
